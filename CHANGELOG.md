# Changelog

## 0.1.0-beta.1 - 2026-09-01

Initial public beta/testing scaffold.

- Added ESP32 and ESP32-C3 PlatformIO targets.
- Added BME280 acquisition and generic analog UV input.
- Added persistent NVS configuration.
- Added Web setup console and browser firmware update.
- Added low-cost OOK/ASK transmitter support through a configurable GPIO.
- Added Oregon Scientific OSV3 Manchester transmitter core.
- Added THGR810 / THGN801 (`F824`) encoder.
- Added UVN800 (`D874`) encoder.
- Added PCR800 (`2914`) and WGR800 (`1984`) bench encoders pending console validation.
- Added configurable channel, rolling ID, timing, repeats and calibration.
- Added staged WMR88/WMR200 + companion LILYGO validation plan.
- Added CI builds for ESP32 and ESP32-C3.

### Status

**BETA / TESTING**. No claim of validated compatibility with original WMR88/WMR200 consoles is made until the planned hardware tests are completed.
